About

What this site is

This is a small practice site built to learn the fundamentals of HTML and CSS -- semantic structure, a responsive nav, an image gallery, and a working contact form. Every page shares the same nav and footer, styled from one shared stylesheet (css/style.css).

What's inside

  • Semantic HTML5 elements (nav, main, footer, figure)
  • A mobile nav toggle powered by a few lines of JavaScript
  • An accessible contact form with labelled fields
  • A responsive image gallery built with CSS Grid
